# Brainstorming Skill

Turn rough ideas into fully-developed concepts.

## Process
1. Capture — get the raw idea out, no judgment
2. Expand — generate 5-10 variations or directions
3. Question — ask what reveals the real need
4. Stress-test — what could go wrong with each direction?
5. Select — narrow to 2-3 best options
6. Develop — flesh out the winner in detail

## Frameworks
- SCAMPER (Substitute, Combine, Adapt, Modify, Eliminate, Reverse)
- Six Thinking Hats
- First principles decomposition
- Reverse brainstorming (what would make this fail?)

## Output
Structured brief: problem statement, 3 best directions, recommended path, next actions.
