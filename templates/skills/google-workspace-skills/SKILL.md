# Google Workspace Skills

Full Google Workspace integration: Gmail, Calendar, Chat, Docs, Sheets, Slides, Drive.

## Available integrations

### Gmail
- Read, search, send, draft emails
- Label and organize inbox
- Thread management

### Google Calendar
- Create, read, update, delete events
- Find free time slots
- Meeting scheduling

### Google Docs
- Create and edit documents
- Read document content
- Format and structure

### Google Sheets
- Read and write cell data
- Create charts and formulas
- Import/export data

### Google Drive
- Search and find files
- Upload and download
- Share and organize

## Authentication
Uses OAuth2 with cross-platform support. Set credentials via environment variables:
GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REFRESH_TOKEN
