# RevealJS Skill
Create stunning HTML presentations with Reveal.js.
## When to use
Any presentation, pitch deck, slideshow request.
## Output
Single HTML file with full Reveal.js presentation, animations, and themes.
## Themes available
black, white, league, beige, sky, night, serif, simple, solarized, moon, dracula
## Features
- Speaker notes
- Code syntax highlighting
- Animated transitions
- Responsive scaling
- PDF export via browser print
