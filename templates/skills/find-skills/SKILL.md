# Find Skills Skill
Search and install Claude skills from the marketplace.
## Discovery methods
- Search by capability
- Browse by category
- Filter by compatibility
- Sort by popularity/stars
## Top skill sources
- github.com/BehiSecc/awesome-claude-skills
- github.com/hesreallyhim/awesome-claude-code
- github.com/anthropics/skills
- github.com/travisvn/awesome-claude-skills
## Installation
1. Find the SKILL.md raw URL on GitHub
2. Copy content
3. Claude.ai -> Settings -> Skills -> Install
